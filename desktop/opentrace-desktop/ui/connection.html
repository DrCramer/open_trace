Сервер организации OpenTrace

Исследовательское ПО: не валидировано для диагностики и судебно-экспертной работы. Анализ FSA выполняется локально на этом компьютере; сервер хранит исходные файлы, проекты, утверждённые стандарты и журнал.

Подключение

HTTP не шифрует пароли, сеансы, генетические данные и FSA-файлы. Используйте только в сегментированной доверенной сети; рекомендуется HTTPS через внутренний CA или обратный прокси.

Где хранятся проекты

В режиме сервера команды «Открыть / Сохранить проект» работают с проектами сервера. Если проект редактирует другой пользователь, он открывается только для чтения.

Файлы HID (GeneMapper ID-X)

Файлы .hid (ABIF v3) хранят трассы в зашифрованном виде. Параметры расшифровки берутся при запуске из файла GMp.jar вашей лицензионной установки GeneMapper ID-X 1.6 (обычно C:\AppliedBiosystems\GeneMapperID-X\app\GMp.jar); OpenTrace их не содержит и не передаёт на сервер.
