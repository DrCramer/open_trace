# OpenTrace Desktop — реестр команд и элементов интерфейса (v10.4)

Документ сгенерирован из живого реестра команд `shell.js` (`Shell.commands()` / `Shell.areas()`) всех четырёх окон после сборки меню и панелей (`desktop/opentrace-desktop/tests/e2e/ui_inventory_dump.cjs` + `ui_inventory_md.py`). Поле «до» — снимок того же UI до оболочки (меню через `buildMenubar`, кнопки панелей), снятый на коммите `e4fcfb6`.

**Принцип.** Оболочка — адаптер над существующими обработчиками: каждый пункт меню, кнопка, вкладка и элемент статуса получает стабильный ID `<область>/<id>` (для меню id = ключ i18n пункта), видимость и порядок задаются раскладкой пользователя (`desktop_ui_layout_v1`). Обработчики, алгоритмы анализа, API и форматы данных не менялись. Скрытие убирает один способ вызова: команда остаётся в палитре (Ctrl+Shift+P) и на своих горячих клавишах.

| Окно | Разделов меню до → после | Пунктов меню до → после | Элементов панелей до → после | Всего ID в реестре | Новые ID оболочки |
|---|---|---|---|---|---|
| Главное окно (project.html) | 7 → 8 | 83 → 91 | 21 → 20 | 134 | 20 |
| Окно графиков (plot.html) | 7 → 7 | 90 → 97 | 27 → 34 | 148 | 14 |
| Менеджер панелей (panels.html) | 5 → 5 | 32 → 35 | 12 → 11 | 58 | 10 |
| Менеджер отчётов (report.html) | 4 → 4 | 23 → 26 | 8 → 7 | 44 | 10 |

Пояснения к счёту:

* пункты меню «после» = прежние + 3 пункта оболочки в «Вид» каждого окна (Настроить интерфейс…, Палитра команд…, Восстановить интерфейс); в главном окне добавлен раздел «Графики» (5 команд, все — существующие обработчики: показать графики, журнал правок, смещения бинов, приборы, настройки графиков) только для промышленного вида; в окне графиков — подменю «Фон графиков (это окно)» (4 ID);
* панели: подпись и её выпадающий список («Настройка таблицы:», «Настройка графика:», «Панели:», «Набор бинов:», «Настройка отчёта:») раньше считались двумя элементами, теперь это один элемент (показываются/скрываются вместе); в окне графиков добавлена панель правки аллелей (9 ID — она была и раньше, но не входила в снимок «до», так как это не `.toolbar`);
* desktop-приложение дополнительно имеет раздел «Сервер» (Сервер организации…, Лабораторные стандарты…, Происхождение анализов…) и критичные ячейки статуса `otSync`/`otWs` из `shim.js`; в WEB-снимке их нет (они видны только в desktop).

## Тесты (ссылки в колонке «Тест»)

Все проверки — `desktop/opentrace-desktop/tests/e2e/ui_shell.cjs` (Playwright, Chromium; встроенный пример или локальный набор FSA).

* **T1** — реестр: команды окна зарегистрированы, у каждой активной команды меню есть обработчик
* **T2** — палитра команд: поиск, выполнение команды (Enter), закрытие Esc
* **T3** — скрытие через редактор «Настроить интерфейс…» / API: элемент не показывается, команда остаётся в реестре и палитре
* **T4** — изменение порядка и сохранение после перезагрузки окна
* **T5** — критичные элементы (статус, ⚙, строка состояния, «Стоп») не скрываются даже при записи их ID в раскладку
* **T6** — аварийный сброс Ctrl+Shift+F12 и откат повреждённой раскладки к заводской с сообщением
* **T7** — вкладки рабочих областей и страницы «Графики», «Стандарты», «Журнал»
* **T8** — темы (Системная, Светлая, Графитовая, Тёмная, Контрастная) и независимый фон графиков; генотипы не меняются

## Горячие клавиши вне меню (обработчики `keydown`, не изменялись)

* **Главное окно:** Delete — очистить ячейки; F1 — справка; Ctrl+F1/F2/F3 — Информация/Raw/EPT; Ctrl+] — полный вид Raw/EPT; Ctrl+Shift+1/2/3 — Образцы/Сводка/Генотипы; Ctrl+Shift+R — анализ всего; Ctrl+Shift+N — навигатор; Ctrl+Shift+Z — повтор; Ctrl+Z/I/U/Y/O/S/D/C/V/T/F/G/M/J/N/K… — как в пунктах меню.
* **Окно графиков:** ←/→ — соседний образец/маркер; Delete — удалить выбранные метки; Esc — снять выделение/закрыть меню; Ctrl+1…5, Ctrl+0 — красители, Ctrl+6 — все; Ctrl+Shift+B/M/D/Y/G/N/H/V — бины, оси, подписи; Ctrl+Y/N — ось X в п.н./точках; Ctrl+Q/A/W — таблица; Ctrl+J — следующий маркер; Ctrl+] — полный вид.
* **Менеджер панелей:** Delete, Esc, Ctrl+D, Ctrl+N/M/E/K/Z/C/V/B/H/G, Ctrl+Shift+N/B/M/E/X, Ctrl+].
* **Менеджер отчётов:** F5, Delete, Ctrl+O/S/E/C/X/V/F/G/D/P/L/A.
* **Оболочка (новые, во всех окнах):** Ctrl+Shift+P — палитра команд; Ctrl+Shift+F12 — восстановить интерфейс. Конфликтов с существующими сочетаниями нет (проверено по обработчикам выше; Ctrl+K уже занят «Добавить образцы» и «Индикатор маркера», поэтому палитра не на Ctrl+K). Перехват идёт в фазе захвата, поэтому Ctrl+Shift+P не доходит до Ctrl+P (печать) менеджера отчётов. **NOT VERIFIED:** поведение этих сочетаний в нативных WebView2 (Windows) и WebKitGTK (Linux).
