Проверено в CI (Windows): установленные NSIS- и MSI-пакеты проходят самотест из каталога установки и удаляются без остатка (MSI после NSIS берёт прежний каталог установки из реестра Tauri — в `%LOCALAPPDATA%`; ставьте один из двух вариантов). Не проверено: два монитора, печать, подпись установщиков, длительная работа с реальными FSA, Caddy/TLS с внутренним CA.

Найдено CI: (1) порядок проектов с именами, различающимися только регистром, зависел от файловой системы (исправлено детерминированно); (2) WebView2 Runtime 131 не передаёт запросы всплывающих окон в схему приложения — нужна актуальная версия (десктоп сообщает об этом пользователю).

Сделано: SQLite + миграции, контентное хранилище FSA, API v1, единые пользователи, lease/fencing/ревизии, read-only, WEB не обходит блокировку, резервные копии. **ProjectWorkspace в десктопе**: источник проектов «сервер», открытие на редактирование или только чтение («Проект редактирует …»), heartbeat 25 с, сохранение с ревизией и fencing-токеном, FSA по `sha256`, потеря lease → только чтение, освобождение при закрытии.
